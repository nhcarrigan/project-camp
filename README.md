# Project Camp

Project designed to connect volunteer developers, with open source projects looking for contributors. Built off of the freeCodeCamp ecosystem.

## Features

- **Project Proposals & Submission:** Propose new open source projects (greenfield builds) or feature expansions for existing projects.
- **Community Voting & Curation:** Upvote and review proposals to increase visibility, prioritize development, and prevent spam.
- **Developer Profiles & Skill Matching:** Build profiles showcasing skills and learning goals, with automated matching to projects and relevant external GitHub issues.
- **Automated GitHub Integration:** Automatic repository and project board scaffolding via the GitHub API to jumpstart collaboration with preset templates.
- **Curated Learning Resources:** Integrated learning materials and guides from the freeCodeCamp ecosystem tailored to project tech requirements.
- **Time-Boxed Project Management:** Structured project timelines with milestones and guidance to keep volunteer teams aligned.
- **Reputation System:** Activity-based reputation system rewarding interacting with the platform to help sustain the platform itself.
